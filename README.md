# SekyroKit for iOS

Binary distribution of the Sekyro AI identity verification SDK for iOS (Swift Package Manager and CocoaPods).

The first release candidate is being prepared. `Package.swift` and `SekyroKit.podspec` are added with the
first tagged version; install a tagged version only.
